# Publishing rules
- One standalone portrait illustration per panel; single vertical column; website-controlled white spacing; readable English.
- Generate batches of five separate images where possible. No collages, repeated titles, embedded reader controls or duplicate scenes.
- Require exact script, reference lock and chronological continuity before approving each panel.
- Track each panel as unverified, missing, draft, rejected, approved or published. Never count duplicate drafts as completed.
- Publish a chapter only when all 50 panels are approved and ordered. Test mobile reading before release.
- Existing assets preserved: assets/chapter-001/strip-01.png, strip-02.png, strip-03.png. These are legacy strips, not verified individual panel assets.
- No new artwork or website modifications in this setup. Do not delete existing assets during recovery.
- Public repository warning: scripts and production notes may be visible to readers. Keep credentials and private information out of records.
